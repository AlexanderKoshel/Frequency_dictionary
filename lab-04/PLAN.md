# Лабораторная № 4. Классификация тональности отзывов

Оригинал условия — [Лаб. 4.pdf](Лаб.%204.pdf). В работе сравниваются бинарное кодирование, TF и TF-IDF с логистической регрессией. Для обучения и проверки используется собственный набор учебных отзывов о беспроводной мыши.

## План эксперимента

1. Подготовить `reviews.csv` с 12 обучающими и 4 тестовыми отзывами. Половина каждого набора относится к положительному классу (1), половина к отрицательному (0).
2. Привести русский текст к нижнему регистру и выделить слова. Построить алфавитный словарь только по обучающим отзывам.
3. Построить бинарную матрицу с `CountVectorizer(binary=True)`, матрицу абсолютных частот с `CountVectorizer` и матрицу TF-IDF с `TfidfVectorizer`. TF-IDF использует сглаженный IDF и нормализацию L2.
4. Обучить отдельную логистическую регрессию на каждой матрице. Для тестовых отзывов применить уже обученные векторизаторы, затем вычислить класс и вероятность положительного класса.
5. Повторить сравнение на тех же данных после удаления русских стоп-слов и лемматизации. Сохранить частицы «не», «ни» и «нет». Построить словарь заново по обработанному обучающему набору.
6. Проверить, что отчёт содержит словари, обучающие и тестовые векторы, истинные и предсказанные классы, вероятности и число верных ответов. Сравнить результаты двух запусков.

## Запуск на Windows

Требуются Python 3.12 с pip и Git для получения проекта. Команды PowerShell из папки `lab-04`:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m nltk.downloader stopwords
.\.venv\Scripts\python.exe main.py
```

После запуска открой [RESULTS.md](RESULTS.md). Скрипт перезаписывает отчёт с результатами текущего набора `reviews.csv`.

## Вывод по приложенным данным

- В первом тестовом отзыве «тихо» встречается дважды. В бинарном векторе его координата равна 1, в TF — 2. На этом отзыве вероятность положительного класса без лемматизации составила 77,2% для One-Hot, 83,7% для TF и 59,0% для TF-IDF.
- После удаления стоп-слов и лемматизации словарь сократился с 38 до 32 позиций. «Работает» и «работают» объединились в «работать». Слово «не» осталось отдельным признаком.
- Каждая модель дала 4 верных ответа из 4 в обоих запусках. Предобработка изменила вероятности, а предсказанные классы совпали. Четырёх тестовых отзывов мало, чтобы сделать вывод о превосходстве одного метода.
