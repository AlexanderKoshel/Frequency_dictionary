# Теория РГР №2

- **Корпус** — упорядоченный набор текстов одного языка. Словоупотребление — одно появление слова. Словоформа — написание слова в тексте после нормализации регистра. Лемма — словарная форма. Например, `children` и `child` дают одну лемму `child`. Лемматизация в проекте выполняет отображение «один токен → одна лемма» и сохраняет объём корпуса.
- **Частота и ранг.** Абсолютная частота f равна числу употреблений. Ранг r начинается с 1 и отражает место в списке по убыванию f. При равной частоте порядок лексикографический. IPM = f × 1 000 000 / N, где N — объём корпуса.
- **Закон Ципфа.** При точной зависимости f = c/r произведение f × r постоянно, а наклон графика log f от log r равен −1. В опыте c оценивается медианой f × r. Диапазон и квартили показывают разброс произведения. Отрицательный наклон сам по себе показывает убывание, а соответствие −1 оценивается отдельно.
- **Эмпирический закон Ципфа.** Проверяется связь длины L и частоты f служебных слов. Точная обратная пропорциональность требует постоянства f × L. Коэффициент Спирмена ρ показывает направление монотонной связи. При равных значениях используются средние ранги. Отрицательное ρ означает тенденцию к большей частоте у коротких слов. Служебность проверяется по списку, поэтому омонимы и слова с несколькими функциями могут учитываться вместе.
- **Коэффициент Жуйана.** Для каждого сегмента находится относительная частота слова. μ — среднее этих частот, σ — среднеквадратичное отклонение с делением на число сегментов. D = 100 × (1 − σ / (μ × √(n − 1))). При одинаковых частотах D = 100, при концентрации в одном сегменте D = 0. Частоты в сегментах без слова равны нулю. Суммарный IPM для таблицы рассчитывается по всему корпусу.
- **Трактовка n.** PDF называет n и числом документов, содержащих слово, и числом сегментов. В работе n — общее число сегментов, как в стандартном расчёте Жуйана. При буквальном подсчёте только сегментов со словом знаменатель обращается в ноль для слов, найденных в одном сегменте. Пример из PDF даёт D = 77,756 ≈ 78 для частот 10, 11, 8 и 3. [S. T. Gries, Analyzing Dispersion](https://stgries.info/research/2020_STG_Dispersion_PHCL.pdf)
