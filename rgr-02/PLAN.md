# РГР №2. Статистические исследования частотных словарей

Источник условия — оригинальный PDF «РГР №2» из вложения к заданию. В условии три задания, общий числовой вариант отсутствует. Исходный проект — `work-01` из `main` на коммите `f5712ee`. Лабораторная №4 на `93040a9` служит примером русской лемматизации. Классификатор тональности для расчётов не нужен.

## Этапы и критерии готовности

1. Проверить базу. Запустить тесты токенизации, SQLite, импорта и GUI, проверить CLI на приложенном тексте и повторный импорт. Отдельно запустить лабораторную №4 и сверить её результат. Зафиксировать фактический объём исходных текстов и доступность полного корпуса в `AUDIT.md`.
2. Подготовить вход. Использовать поиск TXT, чтение и токенизацию из работы №1. Отсортировать файлы по пути, пропустить копии с одинаковым SHA-256 и построить два словаря из одних словоупотреблений. Проверка: сумма частот в обоих словарях равна числу токенов, словоформы совпадают с чистым импортом CLI работы №1.
3. Задание 1. Отсортировать слова по частоте с алфавитным разрешением ничьих. Рассчитать `f × r` для каждого слова, оценить `c` по медиане, вывести квартильный разброс произведения и показатель наклона в логарифмах. Построить график данных и модели `c/r` для обоих словарей. Сопоставить результаты и описать отклонения.
4. Задание 2. Отобрать служебные слова по явному списку. Посчитать длину в буквах и произведение длины на частоту, оценить корреляцию Спирмена и сравнить с моделью обратной пропорциональности. Вывести таблицы и график для обоих словарей. При недостатке вариации сообщить, что корреляция не определена.
5. Задание 3. Поделить поток токенов на четыре последовательных сегмента с разницей размеров не более одного токена. Сохранить границы при лемматизации. По частотам в сегментах вычислить D и записать для каждого слова относительную частоту на миллион, ранг и D. Проверить D вручную на примере из условия, на равномерном и односегментном распределениях.
6. Подготовить отчёт. Оформить титульный лист, содержание и три задания с новой страницы. Подписать и пронумеровать графики и таблицы. В отчёт внести показатели фактического запуска, полные таблицы оставить рядом в CSV. Проверить экспорт в Word 97–2003 и постраничную вёрстку.
7. Описать проект по образцу `AlexanderKoshel/WEB/Task_1/SKILL.md`. Приложить сухую теорию, повторить сквозной запуск, сохранить этапы в ветке `rgr-02` и проверить публикацию.

## Запуск

Команды PowerShell из корня `Frequency_dictionary`. Нужен Python 3.12 с pip.

```powershell
cd rgr-02
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py en ../work-01/texts/english
.\.venv\Scripts\python.exe -m unittest -v
```

В Linux и macOS используй `python3 -m venv .venv` и `.venv/bin/python`. Каталог `out/en` получит CSV, два PNG, `summary.json` и `report.docx`. Контрольный прогон с оригинальным текстом работы №1 сохранён в [example](example).

## Прогон на полных корпусах

Английский, русский и белорусский корпуса из Википедии можно собрать по инструкции [CORPORA.md](CORPORA.md). Пробные английский и русский корпуса из того же источника хранятся в `corpora-sample/`.

Передай каталоги текстов из работы №1. Все TXT в одном запуске должны использовать одну кодировку. Параметр `--encoding cp1251` задаёт Windows-1251. При необходимости `--function-words путь.txt` подставляет утверждённый список служебных слов, по одному слову или несколько слов через пробел в каждой строке.

```powershell
.\.venv\Scripts\python.exe main.py en 'D:\путь\к\english'
.\.venv\Scripts\python.exe main.py ru 'D:\путь\к\russian'
git clone --depth 1 --branch r2.17 https://github.com/UniversalDependencies/UD_Belarusian-HSE.git "$env:TEMP/UD_Belarusian-HSE-rgr2"
.\.venv\Scripts\python.exe main.py be 'D:\путь\к\belarusian' --be-lexicon "$env:TEMP/UD_Belarusian-HSE-rgr2/be_hse-ud-train.conllu"
```

Для белорусского допускается другой размеченный CoNLL-U. Приведённый файл Universal Dependencies используется как словарь словоформ и лемм. Исследуемый корпус задаётся отдельным аргументом. У лемматизатора нет контекстного разрешения омонимии. Неизвестная словоформа сохраняется. При необходимости `--parts 4` можно заменить другим числом непустых сегментов.

Параметры `--author "Фамилия Имя Отчество" --course 3 --group 12` заполняют титульный лист. Для формата EDU открой созданный `report.docx` в Word и сохрани в формате «Документ Word 97–2003 (*.doc)». В LibreOffice из `rgr-02` используй `soffice --headless --convert-to "doc:MS Word 97" --outdir out/en out/en/report.docx`. Подставь нужный каталог языка. Отчёт каждого запуска относится к одному корпусу, а вариант словаря указывается внутри каждого задания.
