# Этап 9. Исправление слова

Это интересная часть.

Допустим:

```text
автомобил → 153
автомобиль → 1200
```

Пользователь исправляет:

```text
автомобил
        ↓
автомобиль
```

Получаем:

```text
автомобиль → 1353
```

То есть:

```text
old_word
     ↓
new_word

если new_word существует:
    frequency(new_word) += frequency(old_word)

удалить old_word
```

Это уже хорошая задача на:

* SQL transactions;
* UPDATE;
* DELETE;
* проверки существования;
* бизнес-логику.
