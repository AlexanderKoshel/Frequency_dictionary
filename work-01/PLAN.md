# Работа № 1. Частотные словари

Оригинал задания хранится рядом в файле «Работа №1.pdf».

## План и состояние

- [x] Реализовать выделение слов с учётом алфавита, регистра, дефиса и апострофа.
- [x] Считать абсолютную частоту словоформ для русского, английского и белорусского языков.
- [x] Сохранять словари в SQLite и пополнять их из TXT-файлов.
- [x] Добавить выбор языка, поиск по началу слова, четыре режима сортировки и статистику.
- [x] Добавить исправление с объединением частот, удаление с подтверждением и добавление слова с нулевой частотой.
- [ ] Собрать и импортировать реальные корпуса объёмом не менее 5 000 000 словоупотреблений на язык. В Git есть небольшой английский пример для проверки.
- [ ] Сверить итоговые объёмы по каждому языку и продемонстрировать поиск, сортировку и обновление словаря.

## Запуск

Из этой папки, с Python 3.11 или новее:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m src.main
```

В Linux и macOS выполняй те же команды через `.venv/bin/python`. Локальная база по умолчанию находится в `data/dictionary.db`. Для работы с другой базой передай `--db путь`.

Выбирай язык и кодировку перед импортом. Поддерживаются UTF-8, UTF-16, Windows-1251 и Windows-1252. Повторный импорт файла с тем же SHA-256 для выбранного языка пропускается. После изменения файла он импортируется как новый источник.

Для консольных команд достаточно стандартной библиотеки Python:

```bash
python -m src.main import en texts/english
python -m src.main import ru texts/russian --encoding cp1251
python -m src.main import be texts/belarusian
python -m src.main stats en
python -m src.main search en ca --sort frequency --desc --limit 20
```

## Проверка

```bash
python -m unittest discover -s tests -v
python tests/benchmark_import.py
```

Тесты интерфейса требуют PySide6. На Linux без монитора запускай их с `QT_QPA_PLATFORM=offscreen`. Проверка производительности использует временные синтетические данные. Для сдачи нужны реальные корпуса.
