# Частотные словари

Учебное настольное приложение на Python 3.11+ / PySide6 / SQLite.
Поддерживает русский (`ru`), английский (`en`) и белорусский (`be`) языки.

## Запуск на Windows

Откройте PowerShell в корне проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m src.main
```

Linux / macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m src.main
```

Также поддерживается `python src/main.py`. База по умолчанию —
`data/dictionary.db` в корне проекта, независимо от рабочей папки.
Другая база: `python -m src.main --db /path/to/dictionary.db`.

## Возможности

- Смена языка, буквальный поиск по началу слова (без учёта регистра).
- Алфавитная сортировка и сортировка по частоте в обоих направлениях.
  Учитывается положение `ё`, `і`, `ў` в алфавите; равные частоты разрешаются по алфавиту.
- Постраничная таблица по 200 строк, общее число словоупотреблений и уникальных слов.
- Добавление слова с частотой 0. Повторное добавление не сбрасывает частоту.
- Исправление написания с суммированием частот, если новое слово уже существует.
- Удаление только после подтверждения в интерфейсе.
- Импорт одного/нескольких TXT-файлов или папки со всеми подпапками.
- Фоновый импорт, отображение хода работы, автоматическое сохранение в SQLite.
- UTF-8 (включая BOM), Windows-1251, UTF-16 и Windows-1252: выберите кодировку перед импортом.
- Повторные файлы с одинаковым SHA-256 в одном языке пропускаются даже после переименования.
  Изменённый файл считается новым источником и добавляется целиком, а не заменяет прежние частоты.
- Ошибка чтения отменяет весь проблемный файл; предыдущие успешно импортированные файлы сохраняются.

Выберите язык **до** импорта: автоматического определения языка нет. Из смешанного текста
принимаются слова выбранного алфавита; слова со смешанными алфавитами отбрасываются.
Словоформы считаются отдельно, лемматизации и удаления стоп-слов нет.
Регистр и Unicode NFC нормализуются, внутренние дефисы/апострофы сохраняются;
типографские варианты апострофов/дефисов приводятся к обычным знакам.

При импорте файлы читаются блоками по 64 КиБ; слова на границах блоков не разрываются.
Счётчики сбрасываются в БД каждые 50 тысяч словоупотреблений. Приложение ждёт завершения
импорта перед закрытием окна, чтобы не прервать транзакцию.

## Корпуса и требование 5 млн слов

**В репозитории пока нет корпусов по 5 млн словоупотреблений на каждый язык.**
В `texts/english/test_text_0.txt` оставлен исходный небольшой пример, пригодный для проверки.
Он не является полноценным корпусом. Русский и белорусский словари изначально пусты.

Для выполнения требования задания нужны настоящие TXT-корпуса на трёх языках,
которые разрешено использовать. Импортируйте их через интерфейс или консоль.
Повторение одного небольшого текста не заменяет корпус.
Индикатор показывает прогресс каждого языка к 5 000 000 импортированных словоупотреблений.
Объём импортированного корпуса хранится отдельно от суммы текущих частот, которая
может уменьшиться после удаления слов. История источников хранится в таблице `imports`
(путь, SHA-256, число слов, время импорта).

## Работа без графического интерфейса

Для консольных команд достаточно стандартной библиотеки Python, установка Qt не нужна:

```bash
python -m src.main import en texts/english
python -m src.main import ru texts/russian --encoding cp1251
python -m src.main import be texts/belarusian
python -m src.main stats en
python -m src.main search en ca --sort frequency --desc --limit 20
```

Каталоги `texts/russian` и `texts/belarusian` создайте и наполните самостоятельно.
Аргумент `--db`, если нужен, указывается перед подкомандой.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Без PySide6 тесты интерфейса будут пропущены. На сервере без монитора:

```bash
QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
```

Тесты проверяют языковые правила, все границы блоков, CRUD, слияние частот,
постоянное хранение, поиск/сортировку/страницы, кодировки, защиту от повторного
импорта и откат частичных пакетов при ошибке декодирования, а также действия GUI.
В GitHub Actions настроены проверки ядра на Python 3.11–3.13 и GUI на Python 3.12.

## Структура

- `src/parser/` — поиск файлов, чтение блоками, нормализация и выделение слов.
- `src/database/repository.py` — хранение, запросы, статистика, изменение слов.
- `src/dictionary/frequency.py` — потоковый импорт и транзакции.
- `src/ui/main_window.py` — окно и фоновый импорт.
- `src/main.py` — графический и консольный запуск.
- `tests/` — проверки ядра и интерфейса.
- `PLAN.md` — исходный учебный план, сохранён для справки.

База и локальное окружение исключены из Git. Для резервного копирования закройте
приложение и скопируйте `data/dictionary.db`.

Дополнительная проверка объёма: `python tests/benchmark_import.py`.
Она создаёт временные синтетические тексты по 5 млн слов на язык,
проверяет точность подсчёта и удаляет их вместе с временной БД.
Это проверка производительности, а не выполнение требования о реальных корпусах.
